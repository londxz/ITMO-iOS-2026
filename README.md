# itmo_iOS

## Unit-тесты

`NewsAppITMOTests` содержит тесты `NewsViewModel` на Swift Testing:

- первая загрузка: успех, пустой ответ, отсутствие новости дня, ошибки обоих запросов;
- исключение новости дня из списка и дубликатов при пагинации;
- переход между страницами, конец ленты, защита от повторных запросов и повтор после ошибки;
- refresh: замена данных, сброс пагинации, сохранение ленты при ошибке и восстановление после ошибки первой загрузки;
- отмена при уходе с экрана и refresh, игнорирование поздних ответов отменённых запросов.

В Xcode откройте `NewsAppITMO/NewsAppITMO.xcodeproj`, выберите схему
`NewsAppITMO` и iOS Simulator, затем нажмите **⌘U**.

Из корня репозитория:

```sh
xcodebuild test \
  -project NewsAppITMO/NewsAppITMO.xcodeproj \
  -scheme NewsAppITMO \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:NewsAppITMOTests \
  CODE_SIGNING_ALLOWED=NO
```

Имя симулятора замените на установленное у вас. Тестовый target использует Swift 6;
для сборки нужен полный Xcode с iOS SDK.

Тесты внедряют `ControlledNewsRepository`: он записывает параметры запросов
и позволяет явно завершать каждый запрос успехом или ошибкой. Отмена записывается,
но не завершает запрос автоматически — это позволяет проверить поздние ответы.
Ожидание событий ограничено пятью секундами; задержки для синхронизации и реальные
сетевые запросы в тестируемой ViewModel не используются.
